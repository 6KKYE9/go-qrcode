# go-qrcode

编解码这种小事，犯不着每次都跑在线工具网站溜一圈。

二维码生成器，把文本/URL 编码成二维码打印到终端。

```powershell
go run . -text "https://example.com"
go run . -text "hello world" -o qr.txt
```

说明：

- 仅支持**字节模式 + L 级纠错**，覆盖版本 1~10，常见短链接、文本、WiFi 配置够用。
- 算法在 `qrcode.go`：比特流构造 → 容量填充 → Reed-Solomon 纠错（GF(256)）→ 矩阵绘制（定位/时序/数据模块）→ 8 种掩码择优 → 格式信息。
- 终端用 `#` / 空格渲染模块，手机扫码即可识别。

生成的码字流和模块矩阵拿 Python `qrcode` 库当基准逐格对过（同为字节模式 + L 级的前提下），版本 1 和版本 2 都是完全一致的。

踩过的坑，留个记录：

- 之字形填充取数据位时要按 MSB→LSB 走，`data[i] >> (7-bit)`。之前写成固定 `>> 7`，等于把每个字节的最高位重复放了 8 遍。
- 格式信息横向那份，第 8 位落在列 7 而不是列 6，差一格整个格式区就废了。
- 掩码惩罚规则 4 的黑白比例是**截断**取整，不是四舍五入到最近的 5%，否则选出来的掩码会和标准实现不一样。
- 对比结果时注意：参考库会自动挑数字字母混合模式，本项目固定字节模式，不强制对齐模式的话两边码字天然对不上。

测试覆盖版本选择、矩阵方阵性、ASCII 渲染、Reed-Solomon 码字长度、定位图案位置，以及一条和参考库对齐的完整码字流断言。
